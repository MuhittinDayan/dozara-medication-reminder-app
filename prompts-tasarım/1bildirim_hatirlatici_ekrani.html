Tasarım Kararları
1
Kilit ekranından direkt onay
Kullanıcı uygulamayı açmak zorunda kalmadan "Aldım / Ertele / Atla" yapabiliyor. Yaşlı kullanıcılar için bu oyun değiştirici — özellikle telefon kilidini açmakta zorlananlar için.
2
Sesli Türkçe hatırlatma
Flutter TTS ile "Aspirin dozunuzu almayı unutmayın" gibi Türkçe sesli bildirim. Görme güçlüğü çeken yaşlı kullanıcılar için kritik erişilebilirlik özelliği.
3
Gemini etiketli alarm
AI'ın önerisiyle değiştirilen alarmda "✦ Gemini tarafından ayarlandı" etiketi var. Kullanıcı güveni inşa eder — ne zaman ve neden değiştiğini biliyor.
4
Aile bildirimi toggle
Doz alındığında aile üyelerine push notification gitsin seçeneği. Bakıcı modunun bildirim tarafı — uygulamayı tek kullanıcıdan aile platformuna taşıyan özellik.

// flutter_local_notifications kurulumu
Future<void> scheduleMedicineReminder(Medicine med) async {
  await notifications.zonedSchedule(
    med.id,
    '${med.name} · ${med.doseLabel}',
    'Dozunuzu almayı unutmayın 💊',
    nextInstanceOfTime(med.reminderTime),
    notificationDetails,
    androidScheduleMode: AndroidScheduleMode.exactAllowWhileIdle,
    matchDateTimeComponents: DateTimeComponents.time,
  );
}
// Türkçe sesli hatırlatma (flutter_tts)
final tts = FlutterTts();

Future<void> speakReminder(String medicineName) async {
  await tts.setLanguage('tr-TR');
  await tts.setSpeechRate(0.45); // yaşlı kullanıcı için yavaş
  await tts.speak(
    '$medicineName dozunuzu almayı unutmayın.',
  );
}
// Kilit ekranı aksiyon butonu (notification action)
const notifDetails = NotificationDetails(

      AndroidNotificationAction('snooze', '⏰ 15 dk'),
