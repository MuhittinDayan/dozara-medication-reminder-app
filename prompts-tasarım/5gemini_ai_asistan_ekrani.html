Tasarım Kararları
1
Renkli yanıt kartları — anlam kodlama
Yeşil = güvenli, Sarı = uyarı, Mor = bilgi. Düz metin yerine kart yapısı kritik sağlık bilgisini vurgular ve taranabilir kılar.
2
Quick chip'ler — boş ekran korkusunu önler
Kullanıcı "ne soracağını bilmiyorum" hissiyle donup kalmasın. Sık sorulan 3 soru hazır chip olarak sunulur.
3
Haftalık analiz — proaktif AI
Kullanıcı sormadan önce Gemini kaçırılan doz paternini tespit eder ve alarm önerisi sunar. Actionable button direkt yanıt içinde.
4
Ses girişi — yaşlı kullanıcı dostu
Mikrofon butonu her zaman görünür. Yazmakta güçlük çeken kullanıcılar konuşarak soru sorabilir.

// Gemini sohbet mesajı gönderme
Future<String> askGemini(String userMessage) async {
  final systemPrompt = buildSystemPrompt(
    user: currentUser,
    medicines: activeMedicines,
    compliance: weeklyCompliance,
  );
  final response = await gemini.generateContent([
    Content.text(systemPrompt),
    ..._chatHistory,
    Content.text(userMessage),
  ]);
  _chatHistory.add(Content.text(userMessage));
  _chatHistory.add(Content.model([
    TextPart(response.text ?? '')
  ]));
  return response.text ?? '';
}
// Yanıt tipine göre renkli kart
Widget buildResponseCard(GeminiResponse res) {
  return switch (res.type) {
    ResponseType.safe => SafeCard(text: res.text),
    ResponseType.warning => WarningCard(text: res.text),
    ResponseType.info => InfoCard(text: res.text),
    _ => PlainBubble(text: res.text),
  };
}
